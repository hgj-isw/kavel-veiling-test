API (Cloudflare Worker + D1):
  Zie workers/README.md
  Jasper: wrangler login → D1 → secret ACCESS_CODE → deploy
  Build met: VITE_API_URL=https://<worker>.workers.dev

Bouwen & deployen frontend:

  npm install
  VITE_API_URL=… npm run build:pages   # of zonder URL = mock in browser
  # push dist/ naar branch gh-pages (pad /)

Settings → Pages → Deploy from branch → gh-pages → / (root)
