GitHub-repo aanmaken (vanaf jouw laptop, account hgj-isw)
=========================================================

1. Kopieer deze map lokaal (of download uit de projectstore:
   docs/github-test-app/).

2. In de map:

   git init
   git add .
   git commit -m "Eerste versie: test-kavelveiling met nepdata"
   gh auth login   # eenmalig, als dat nog niet gebeurd is
   gh repo create hgj-isw/kavel-veiling-test --public --source=. --remote=origin --push

   (Gebruik --private als de testsite niet openbaar mag.)

3. GitHub Pages:

   npm install
   npm run build:pages

   Optie A — Actions / Pages UI: Settings → Pages → Source = GitHub Actions
   of branch `gh-pages` / map `docs`.

   Optie B — snel met gh-pages package:

   npx gh-pages -d dist

4. Open: https://hgj-isw.github.io/kavel-veiling-test/

Let op: in deze cloud-agent stond `gh` niet ingelogd, daarom kon de repo
hier niet automatisch worden aangemaakt.
